# Provatsoft Vendor Receipt

Enterprise-grade SaaS receipt generation platform built with Next.js, TypeScript, Tailwind CSS, Supabase, React PDF, and Resend.

## Features

- Multi-template receipt builder
- Admin & vendor dashboards
- PDF generation and email delivery
- Supabase auth and storage
- Premium enterprise UI

## Getting Started

1. Install dependencies: `npm install`
2. Run dev server: `npm run dev`
3. Add Supabase and Resend environment variables in `.env.local`
